# Blobby

Make animated blob gradient backgrounds in the browser.

- Pick up to six colours plus a background, or pull a palette from a photo (upload or drag and drop)
- Shape: blob size, soft or defined edges, wobble
- Motion: drift distance and speed; every animation is a seamless loop
- Grain texture
- Save a PNG (up to 4K) or record the loop as a video (MP4 where the browser supports it, otherwise WebM)
- Copy a link that reopens the exact background, or copy the hex codes

Shortcuts: Space pauses, H hides the controls, R shuffles blob positions.

Plain HTML, CSS and JavaScript with a WebGL shader. No build step: Vercel serves the folder as a static site.
